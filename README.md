# IELTS 4.5 学习

适合英语初学者使用的静态网页。按 500 个学习日的计划推进英语学习，覆盖词汇、音标、语法、听力、阅读、写作、口语记录与阶段检查。

## 特点

- **纯静态**：四个应用文件加本地素材，无构建工具、无后端、无登录。
- **按学习日推进**：不是日历自动走。点「完成今天」才前进一天，忙的时候停在那里不会丢内容。
- **间隔复习**：1、2、4、8、16、32、64、128 个学习日，答「不认识」退两格。
- **数据只在本地**：存在浏览器的 localStorage 里，可随时导出备份；手机与电脑的数据互不相通。
- **可选接 AI**：按当前进度出阅读题、给作文打分，接口可配 DeepSeek 或其他 OpenAI 兼容服务。不配也能用，会退回复制粘贴的方式。
- **适配手机**：底部固定导航，输入框字号 16px 防止 iOS 自动放大。

## 快速开始

电脑上直接用 Chrome 打开 `index.html`。不需要安装任何东西。

手机上通过 GitHub Pages 访问，建议长期使用同一个地址，因为 localStorage 按网址隔离。

首次使用：设置 → 计划开始日期 → 保存。

## 运行测试

```
node --test
```

需要 Node.js 20 或更高版本，不安装任何 npm 包。当前 557 个用例全部通过。

## 学习计划

500 个学习日，平均每天 60 到 90 分钟。

| 项目 | 起始 | 频率 |
|---|---|---|
| 听力 | 第 1 天 | 每天 |
| 音标 | 第 1 天 | 每天，到第 30 天止 |
| 语法 | 第 8 天 | 每 4 天一条，共 120 条 |
| 口语 | 第 15 天 | 每天一道 Part 1，每周一张 Part 2 |
| 阅读 | 第 61 天 | 每 3 天一篇 |
| 写作 | 第 121 天 | 每 7 天一篇 |
| 检查 | 第 50 天 | 每 50 天一次 |

词汇：3000 个，前 240 天按每天 10 到 15 个推进完毕，第 241 天起只做复习与练习。

## 已知限制

- 到期复习必须全部作答才能完成今天。这是刻意的严格模式，忙的时候会卡住。
- 阅读题与作文评分由 AI 生成，质量与费用会有波动；同一篇不要反复点评分。
- 口语只在应用内显示话题并记录自评分，实际练习需借助第三方工具。
- 听力 49 课循环使用，一课约三分钟，填不满每天二十分钟，需重复听或配合外链。
- 听写练习不写入存储，刷新后从第一个词重新开始。
- 数据只在本机浏览器，换网址或清理网站数据会导致记录丢失，请定期导出备份。
